# المهمة: إكمال ربط GitHub

الحالة: APPROVED
جهة الاعتماد: المستخدم، ضمن طلب تجهيز البيئة والمستودع الخاص؛ متابعة ChatGPT للتنفيذ.

## النطاق المعتمد

المستودع الخاص أُنشئ من المتصفح: https://github.com/MishalFayez/TheLivingWorld
المجلد المحلي مربوط به باسم origin. المطلوب رفع تاريخ Git الحالي ووسم baseline بعد التحقق من الخصوصية، ثم مطابقة الفرع المحلي والبعيد.

يجوز تجهيز نسخة محمولة من GitHub CLI من مستودع cli/cli الرسمي داخل .dev/tools/ المستثنى من Git، دون تثبيت إداري أو تغيير سياسات النظام. استخدم تسجيل الدخول المعتاد، ولا تقرأ ملفات كلمات المرور أو رموز الاسترداد ولا تطبع مفاتيح الدخول. أي شاشة تفويض تحتاج تدخل المستخدم تُترك له؛ لا تتجاوزها.

## قيود التنفيذ

- لا تغيّر ملفات اللعبة أو اختبارات سلوكها أو التصميم.
- افحص الحالة الحالية واحفظ التغييرات القائمة.
- تحقق من حساب MishalFayez وأن المستودع PRIVATE قبل الرفع.
- ارفع main والوسم baseline-design-resolution-2026-11-20 دون force، وتوقف إذا وُجد تاريخ بعيد متعارض.
- لا تنشئ مستودعًا آخر ولا توسع صلاحيات تطبيقات أخرى.
- اكتب النتيجة الفعلية والعوائق في collaboration/results/GITHUB_SETUP.md.
