Summary of the binding requirements (the full package text was pasted in chat; its parts are reproduced in order):

1. **Baseline audit before modifications:** formulas, stats, mitigation, level scaling, all attacks / skills / recovery / costs, Vanguard Guard / Resolve / threat, Worldweaver spells / healing / interactions / Sanctum, Reaver Dance / Edge / Weave / stamina, enemy tracking / rotation / hitboxes / commitment / damage, i-frames / buffering / cancels / enemy movement, the 57 playable Augments, paths, camera + lock-on, tooltips, benchmark tools. Baseline table of real values and observed outcomes.
2. **Balance philosophy:** Vanguard = defensive tank (durability, Guard, threat, protection; never helpless solo). Worldweaver = magic DPS / healer / support, healing in BOTH paths, no healer-only build. Reaver = pure physical DPS / evasive duelist; survives through mobility and avoidance — no healing, shielding or passive durability to compensate for broken dodging.
3. **Numerical targets (provisional):** Reaver ~25–45% higher practical sustained single-target DPS than Vanguard with competent core play; Worldweaver meaningful magic DPS, may win in AoE / interactions. Every class must solo the Level 10 boss with its intended mechanics; no deaths from unavoidable tracking / hitbox / input delay. Survivability metrics (time to death with / without defence, damage avoided, unavoidable hits, correct dodges that still take damage). Path warning threshold ~10–15% DPS difference without compensation (not forced equality).
4. **Reaver dodge:** audit Combat Weave (distance, duration, speed curve, startup, recovery, i-frames, stamina, animation, cancel / buffer, collision, tracking). Test envelope: lateral 2.5–3.2m, forward 2.3–3.0m, back 3.2–4.0m (experimental; better values allowed if measured). Space = dedicated, readable defensive action; correct i-frame alignment; no camera snap; Committed Cut stays committed. Restrained feedback for dodge start / successful avoidance / completion; no HUD meter; no Evasive Counter. No Reaver HP / armor / damage change before avoidance is measured.
5. **Enemy tracking and commitment:** audit every enemy attack; separate rotation from lunge; three phases (early telegraph tracking, late telegraph reduced tracking, committed active attack). Attack-specific commitment (initial guide: lock most of the direction during the final ~20–35% of windup for ordinary melee). Verify dodge left / right / back at different timings, movement outside the hitbox, i-frame dodges, lock on / off; record facing change before impact, lock time, impact time, player position / damage, movement vs i-frame avoidance.
6. **Reaver camera jitter:** reproduction matrix (A only, A+LMB, A+Space, A+Q, repeated lateral Dance, locked / unlocked, multiple enemies, near walls); find the real root cause from frame-by-frame camera data; no blanket smoothing; no change to other classes' cameras if Reaver-specific.
7. **Worldweaver casting wheels (redesign):** LMB and RMB each open their own wheel while held; selection and charging are one gesture; release casts the selected spell; no Q / V spell switching (restore Q / V). Wheel near the reticle, elemental sectors, spell icons, selected highlight, charge progress, full-charge cue, elegant, not opaque. Mouse vector selects; changing sector restarts the charge from zero; same sector continues. Release respects minimum charge (no exploit). Quick tap casts the last selected spell for that button without flashing. Camera rotation suppressed while navigating, restored on release. Independent LMB / RMB spell sets from the existing loadout / Spellbook; no damage-only / heal-only split. Preserve F, E, utility, heal targeting, third slot, formations, unlocks, interactions, Arcane Mastery, paths. Cancellation matrix (dodge, stagger, death, UI, mana, invalid heal target, switching, neutral centre, fast cursor, target change): no free spells, no lost resources, no double cast, no stuck wheel, no camera rotation.
8. **Skill tooltip redesign:** default = name, one sentence, current effect (damage / healing / shield, Poise when important, cost, cooldown / charge when relevant), scaling (stat abbreviation, stat value, its exact contribution, +1 point effect). Colour the numbers (stat colours for stat contributions, effect colours for effect types); never colour-only. Real formulas only (no MAS on direct heals, no VIT as damage). Shift = formula / crit / phases / mitigation. Readable in 2–4 s. Shared DamageCalc, accurate before / after.
9. **Augment card redesign:** name, icon, rarity, one concise sentence of the gameplay change, highlighted key number, condition / cooldown if needed, one synergy sentence only for real mechanical value. Specific text (no filler). Coloured numbers by context (stat colours only for stat scaling). Detail screen keeps formulas / eligibility / tradeoffs / before-after / legacy notes. Values from the resources; gameplay unchanged; layouts checked.
10. **Augment balance audit:** usefulness beyond unit tests (trigger frequency, noticeability, meaningful benefit, decision change, competition, solo / party, before Lv10). Focus: Precise Defense, Rewoven Spell, Circling Predator, Living Confluence, narrow-timing cards without feedback, weak synergies. Improve reliability / clarity / tactical usefulness within existing mechanics, not raw damage; flag redesigns. Keep Healing Ember, Purifying Confluence, Fortress Breaker in the backlog.
11. **Full class balance adjustment:** levels 1 / 3 / 4 / 5 / 8 / 10; no augments / anchor / three / synergy / alternative; solo / party; basic / agile / shielded / caster / elite / boss enemies; metrics (DPS, burst, TTK, damage taken / avoided, time to death, HPS / effective healing, shielding, guard prevented, threat share, stamina / mana uptime, attack uptime, Poise breaks, dodge success, augment triggers / min, class mechanic use). Fix correctness first, re-measure, then tune (damage multipliers, recovery, charge, costs, regen, Poise, enemy damage / commitment, reductions, movement, dodge, cooldowns, augment coefficients) with small documented changes (~5–15% initial; larger for movement / responsiveness). Player-like scripted boss tests for every class.
12. **Mage and Vanguard path evaluation:** Living Fortress, Aegis Reversal, Elemental Crossroads, Spell Threading must produce visible differences: plain explanations, visible activation cues, clear Level 4 previews, before / after measurements, a demonstration encounter.
13. **Testing:** no test changed just to pass; full regression with real counts; no claim of visual validation from script tests.
14. **Milestones:** A diagnosis, B combat corrections, C Worldweaver control, D UI clarity, E balance; commit by milestone; keep the safe test session; never modify the real save.
15. **Report:** `collaboration/results/COMBAT-BALANCE-UX-006.md` (baseline, bugs, fixes, tracking before / after, dodge before / after, camera root cause, wheel implementation, screenshot review, tooltip examples, class balance tables, solo boss results, path comparisons, augment audit, every numerical change with reason, test results, remaining issues, commits) + a concise playtest guide.

**Final acceptance:** reliable Reaver avoidance of correctly timed attacks; readable enemy commitment; camera jitter resolved or precisely documented; LMB / RMB wheels (not Q / V); identities preserved; tooltips with real coloured scaling; readable augment cards; valid class-specific balance measurement; feasible solo Level 10 path for every class; all adjustments documented and regression-tested. Push without force, no PR, no merge; final approval stays with the owner and ChatGPT.
