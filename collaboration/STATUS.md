# حالة العمل

تحديث التحقق من سطح المكتب: رُبط Claude Desktop مباشرة بهذا المجلد، وقرأ تعليمات العمل وشغّل الاختبارات وكتب results/DESKTOP_VERIFICATION.md. النتيجة الحالية 549 نجاحًا وفشل واحد من 550؛ حالات الحفظ التسع لم تتكرر. الفشل المتبقي يخص استقلالية التقدم عند تبديل الكلاس. لم تتغير ملفات اللعبة الأصلية.

حساب GitHub مرتبط الآن بـChatGPT، لكن متصفح إنشاء المستودع يحتاج تسجيل دخول مستقل. لا يوجد مستودع بعيد أو رفع حتى الآن. Git Bash وGitHub CLI غير متوفرين في المسارات المفحوصة؛ عمل تحقق Claude عبر PowerShell والمسارات المحلية الصريحة.

النسخة الأساسية: AshenValley_DesignResolution، تقرير 20 نوفمبر 2026، محرك Godot 4.7.2.

التصميم والميكانيكيات من اختصاص مشعل وChatGPT حصريًا. Claude Code ينفذ المواصفات المعتمدة فقط.

المهمة الحالية: تجهيز بيئة التطوير والتحقق من الاختبارات؛ لا توجد مهمة جديدة معتمدة لتعديل أسلوب اللعب.

المصدر الأصلي بقي دون تعديل. نسخة العمل موجودة في مجلد هذا المستودع. النسخة الاحتياطية موجودة خارج المستودع في ../backups/.

سير العمل: يكتب ChatGPT مهمة دقيقة في tasks باستخدام القالب؛ يعتمدها المستخدم أو ChatGPT ضمن الصلاحية الممنوحة؛ ينفذ Claude في فرع؛ يسجل النتائج في results؛ يراجع ChatGPT التغييرات وتقارير الاختبار قبل الدمج.

للمراجعة في هذه المحادثة المحلية، اطلب قراءة ملفات collaboration مباشرة. المحادثات الأخرى لا تحصل تلقائيًا على ملفات الجهاز. استخدم tools/dev/Handoff.ps1 لتجميع تقرير قابل للإرفاق عند الحاجة.
