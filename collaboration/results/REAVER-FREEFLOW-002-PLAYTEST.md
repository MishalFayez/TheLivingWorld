# REAVER-FREEFLOW-002 — قائمة اللعب البشري

| البند | القيمة |
|---|---|
| الفرع | `feature/reaver-freeflow-002` |
| المحرك | Godot 4.7.2 |
| الحفظ | أي إضافة من لوحة Debug تجعل الجلسة غير محفوظة |

## التحضير

1. أغلق Godot إن كان مفتوحًا، ولا تحفظ أي تغييرات.
2. تأكد من الفرع:
   ```powershell
   git branch --show-current
   ```
   يجب أن تظهر `feature/reaver-freeflow-002`.
3. افتح المشروع، ثم اضغط F5، ثم Continue، واختر Reaver.
4. **عدو للتجربة:** افتح F1، تبويب Spawning، واختر `raider`. هذا العدو يهاجم، وتحتاجه للمراوغة المثالية وPunish.
5. **إن أردت ألا يتغير حفظك:** افتح F1، تبويب Combat، واضغط Swordmaster ثم Free Flow.

## الأزرار

| الزر | الفعل |
|---|---|
| LMB | Flow Strikes. بعد مراوغة مكتملة مباشرة تصبح **Pursuit Slash**، وبعد مراوغة مثالية تصبح **Counter Slash** |
| RMB | Heavy Cut |
| Space | مراوغة |
| 1 / 2 / 3 | Pursuit Cut / Pivot Cut / Decisive Cut |

## القائمة

ضع ✔ أو ✘، واكتب ملاحظة قصيرة لكل بند.

### أ. الاقتراب بعد المراوغة (شكوى اللعب الأولى)

| # | الخطوات | المتوقع | ✔/✘ وملاحظة |
|---|---|---|---|
| 1 | خفيف، خفيف، ثم راوغ **جانبًا** (A أو D مع Space)، ثم LMB فورًا | حركة قطع منخفضة مختلفة، تقترب نحو 1–1.5 م وتصيب غالبًا | |
| 2 | نفس الشيء مع مراوغة **للخلف** (S مع Space، أو Space دون اتجاه) | العدو يبقى بعيدًا (نحو 5.5 م) ولا اقتراب. هذا تطبيق للحد المعتمد 1.5 م (سؤال التصميم 4) | |
| 3 | راوغ، ثم انتظر نحو نصف ثانية، ثم LMB | تعود Flow Strike العادية، دون اقتراب | |
| 4 | Pursuit Slash نحو عدو بعيد (أكثر من 4 م) | لا سحب ولا حركة | |
| 5 | هل يبدو الاقتراب طبيعيًا أم ينزلق أو يقفز؟ | حركة قصيرة متصلة تتوقف عند مدى السيف | |
