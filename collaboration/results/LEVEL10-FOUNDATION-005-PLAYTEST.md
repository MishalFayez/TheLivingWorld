# LEVEL10-FOUNDATION-005 — دليل اللعب البشري

| البند | القيمة |
|---|---|
| الفرع | `feature/level10-combat-augments-005` |
| المحرك | Godot 4.7.2 |
| الهدف | الحكم على: وضوح الأرقام، وحركة Blade Dancer 004، وعجلة التعاويذ، وإحساس Poise Break، وهل تغيّر البطاقات طريقة اللعب |

## 1. التشغيل

1. تأكد من الفرع:
   ```powershell
   git branch --show-current
   ```
   يجب أن تظهر `feature/level10-combat-augments-005`.
2. افتح المشروع في Godot 4.7.2، ثم **F5**، ثم **Continue**.
3. **المسار الآمن لشخصية جديدة (المراجعة 1، الطريقة الموصى بها):**
   1. من شاشة العنوان افتح **Character Selection**، ثم اضغط **Fresh Lv1 Test** بجانب الكلاس. تظهر رسالة "FRESH TEST CHARACTER - nothing is saved".
   2. شخصيتك المحفوظة لا تتغير أبدًا.
   3. للتقدم بسرعة: **Esc**، ثم **"Test session: gain a level"**. يرفع مستوى واحدًا عبر EXP الحقيقي، فتظهر Drafts المستويات **4 و8 و10** تلقائيًا.
   4. فعّل **Party Test** في نفس الشاشة لتجربة بطاقات الحماية والدعم. بطاقات الحليف لا تُعرض في اللعب الفردي.
   5. **Return to Title** يتجاهل الجلسة بالكامل.
   6. كرر لكل كلاس، ولكل مسار (اختر مرساة مختلفة في المستوى 4).
4. **لعدو للتجربة:** F1، ثم **Spawning**، واختر `raider`. فعّل **Lock-on** بـTab.
